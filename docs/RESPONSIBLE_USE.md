# CrawlOps 使用限制与合规要求

CrawlOps 仅提供任务调度与运行管理能力，不代表使用者取得任何系统访问、数据采集、代理服务或数据处理的授权。使用者必须自行确保：

- 对目标系统、代码仓库和数据具有明确授权；
- 遵守目标站点服务条款、robots.txt、速率限制及 API 使用政策；
- 遵守隐私、数据保护、著作权、网络安全和其他适用法律；
- 不用本项目绕过访问控制、验证码、付费墙、技术保护措施或平台限制；
- 不处理、出售或泄露无合法依据取得的个人数据。

内置的外部代理源采集默认关闭。启用或添加任何来源前，应单独审查该来源的条款、授权范围、请求频率和数据处理风险。
